## 특징
- 📅 **30일 플랜** — 하루 분량씩, 출제 빈도 높은 단어부터 (총 3,875개)
- 🧠 **원어민 감각 이미지** — 정의 암기 대신, 접두사·어근을 공간 이미지로 풀어 직관적으로 (예: *reject* = "내밀어진 걸 손으로 도로 뒤로 던져 되돌림 — re-뒤로 + ject던지다")
- 🔊 **발음 듣기** — 브라우저 내장 음성
- ✅ `단어 보기 → 스스로 뜻 떠올리기 → 확인 → 1/2/3 자가평가` (능동 회상). 한 번 본 새 단어는 다시 안 나오고, 틀린 단어는 별도 **복습 세션**에서
- 🔁 전체 다시보기 · 📋 전체 단어 목록(탭하면 뜻) · ↺ Day 초기화
- 💾 **진행상황 자동 저장** · 🌗 라이트/다크 테마

## 웹 버전
`index.html` **한 개로 완결되는 정적 웹앱**입니다. HTML·CSS·JavaScript·단어 데이터가
전부 이 파일 안에 들어 있고 모든 동작이 브라우저에서 실행돼요. 서버·DB가 없어서
파일만 웹에 올려두면(GitHub Pages) 그대로 앱이 됩니다. 진행상황은 기기 브라우저에 저장됩니다.

## 데스크톱 버전 (Windows, Python)
`desktop/` 폴더에 Python(tkinter) 버전이 있습니다. 발음은 gTTS(온라인)→pyttsx3(오프라인) 폴백.
```
desktop/단어암기_실행.bat   더블클릭   (Windows)
```
자세한 사용법은 [`desktop/README_단어암기.md`](desktop/README_단어암기.md) 참고.
