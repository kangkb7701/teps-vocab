## 이게 뭔가요
해커스 텝스 단어장을 바탕으로 정리한 **3,875개 단어**를 30일로 나눠,
`단어 보기 → 스스로 뜻 떠올리기 → 확인 → 1/2/3 자가평가` 방식으로 외웁니다.
채점은 프로그램이 아니라 **본인의 자가평가**로 합니다 (능동 회상, active recall).

## 어떻게 한 파일로 돌아가나요
`index.html` **한 개로 완결되는 정적 웹앱**입니다.
HTML·CSS·JavaScript·단어 데이터가 전부 이 파일 안에 들어 있고,
모든 동작은 **브라우저에서 실행**됩니다. 서버·데이터베이스가 없어서
파일만 웹에 올려두면(GitHub Pages) 그대로 앱이 됩니다. 오프라인에서도 대체로 동작해요.

## 만든 방식
- 단어 데이터는 해커스 텝스 단어장 PDF에서 추출·정리했습니다 (**원본 PDF는 저작권상 포함하지 않음**).
- 데스크톱용 Python(tkinter) 버전도 별도로 있습니다.
- **개인 학습용 프로젝트**입니다.
