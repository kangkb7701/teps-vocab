# TEPS 350+ 30일 단어 암기 프로그램

해커스 텝스 단어암기장 PDF(리스닝/리딩)에서 뽑은 **3,875개** 단어를 30일로 나눠,
`단어 보기 → 뜻 떠올리기 → 확인(발음) → 1/2/3 자가평가 → 간격 반복`으로 암기합니다.

## 실행 방법 (가장 쉬움)
파일 탐색기에서 **`단어암기_실행.bat`** 더블클릭.

> 처음 1회는 자동으로 `vocab.json`(단어 데이터)을 만든 뒤 프로그램이 열립니다.

## 직접 실행 (터미널)
> ⚠️ 그냥 `python`은 Windows 스토어 스텁이라 안 됩니다. **Anaconda Python**을 쓰세요.
```
"%USERPROFILE%\anaconda3\python.exe" parse_vocab.py     # 최초 1회 (vocab.json 생성)
"%USERPROFILE%\anaconda3\python.exe" teps_trainer.py    # 프로그램 실행
```

## 사용법
1. **홈**: Day 1~30 타일 중 선택 → **Day 상세 화면**이 열립니다. `🔁 복습 세션`은 모름/애매로 찍은 약한 단어만 따로.
   - **핵심 규칙**: Day/이어하기에서는 **모든 단어를 딱 한 번씩만** 봅니다. 모름·애매로 찍어도 그 세션에서 **다시 튀어나오지 않습니다.** 틀린 단어는 홈의 `🔁 복습 세션`에서 원할 때 몰아서 복습하세요.
   - **Day 상세 화면** 버튼:
     - `▶ 학습 시작 / 이어서 학습` — 아직 안 본 새 단어만, 중간에 끊어도 다음 단어부터 이어짐
     - `📝 예문 테스트` — TEPS 스타일 **예문 빈칸 4지선다**. 그 Day 전체 단어가 랜덤 순서로 출제
     - `🔁 약한 단어만 다시보기` — **그 Day에서 모름/애매로 남은 단어만** 카드로 다시
     - `🔁 전체 다시보기` — 이미 본 단어까지 그 Day 전체를 처음부터 (진행 기록은 안 건드림)
     - `📋 전체 단어 보기` — 그 Day 모든 단어를 목록으로 한눈에. **단어를 누르면 뜻·이미지·발음** 표시
     - `↺ 이 Day 초기화` — 그 Day의 자가평가·진행 기록만 지우고 '안 본' 상태로 (단어 데이터는 유지)
2. **학습**: 영어 단어가 크게 뜹니다 → 스스로 뜻을 떠올린 뒤
   - **스페이스**(또는 [뜻 보기]) → 한글 뜻 + 품사 + 출제빈도(★) + 🧠 **감각 이미지** + 발음
   - **1**(몰랐음) / **2**(애매함) / **3**(알았음) 키 또는 버튼으로 자가평가
   - **P** 키 또는 🔊 버튼으로 발음 다시 듣기 (자동발음 체크박스로 자동 재생)
   - 🧠 **감각 이미지**: 원어민이 그 단어에서 떠올리는 하나의 감각적 장면·접두사/어근 분해를 한 줄로. (전체 3875단어 수록, `images.json`)
3. **간격 반복(Leitner)**: 1·2로 평가한 단어는 세션 안에서 다시 등장(1=곧, 2=조금 뒤),
   3이면 통과. 다 통과하면 세션 종료 → 요약(평가 분포·약한 단어) 표시.
4. **이어하기**: 진행 상황은 `progress.json`에 자동 저장. 껐다 켜도 복원됩니다.
5. **📝 예문 테스트** (`examples.json`): 단어마다 빈칸 예문 1개 + 오답 3개(같은 Day·같은 품사에서 헷갈리게 선별).
   - **Day 1~30 전 단어 수록 완료** (3,875단어 전부).
   - 보기 선택(1~4키) → 즉시 채점 + 뜻·해석·발음 → 스페이스로 다음 문제
   - **맞히면**: 모름/애매였던 단어는 '알았음'으로 승급 · **틀리면**: 학습했던 단어는 '모름'으로 강등 → 복습 대상
   - 아직 안 본 단어(box 0)는 테스트로 기록이 바뀌지 않아 Day 학습 큐가 유지됩니다
   - 테스트 종료 후 `틀린 것만 재시험` / `틀린 단어 카드 학습` 가능
   - 학습 카드의 뜻 화면에도 ✏️ 예문·해석이 함께 표시됩니다

## 데이터 우선순위
기초(베이직 리스닝·리딩) → 고급 리딩 출제빈도 ★★★ → ★★ → ★ 순으로 앞 Day에 배치.

## 구성 파일
| 파일 | 설명 |
|---|---|
| `parse_vocab.py` | PDF → `vocab.json` 파서 (발음기호 특수폰트 제거, ★=출제빈도) |
| `teps_trainer.py` | tkinter GUI 학습 프로그램 (SRS·TTS·저장) |
| `vocab.json` | 파싱된 단어 데이터 (자동 생성) |
| `images.json` | 단어별 감각 이미지(원어민 직관) 오버레이 — vocab 재파싱해도 유지 |
| `examples.json` | 단어별 예문 빈칸 테스트 데이터 (예문 s · 해석 t · 오답 d) |
| `examples/` | Day별 예문 원본 (day_01~30.json, examples.json으로 병합됨) |
| `progress.json` | 학습 진행 상황 (자동 생성) |
| `teps_mobile.html` / `index.html` | 아이폰용 웹앱 (inject_data.py로 데이터 주입, index.html은 GitHub Pages 배포용) |
| `inject_data.py` | web_words.json + examples.json → 웹앱 HTML 주입·동기화 |
| `audio_cache/` | gTTS 발음 mp3 캐시 (오프라인 재사용) |

## 오디오
인터넷 연결 시 gTTS로 발음 mp3를 만들어 `audio_cache/`에 저장(다음엔 오프라인 재사용).
인터넷이 안 되면 자동으로 pyttsx3(Windows 내장 음성)로 폴백합니다.

## 필요 패키지
`PyMuPDF`(fitz), `gTTS`, `pygame`, `pyttsx3` — 이미 설치되어 있습니다.
```
"%USERPROFILE%\anaconda3\python.exe" -m pip install PyMuPDF gTTS pygame pyttsx3
```
